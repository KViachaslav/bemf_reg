## 📝 Правка ТЗ для агента

### Изменение схемы измерения BEMF

**Было:** измерение BEMF на одном пине (PA0, ADC1_IN0) относительно земли.

**Стало:** измерение BEMF **дифференциально на двух пинах**, потому что мотор питается от +12В жёстко, а ШИМ коммутирует низкую сторону через IRLZ44N.

### 🔌 Аппаратная схема (зафиксировать в комментарии `bemf.c`)

```
+12В ──────┬───────────────┐
           │               │
        [МОТОР]         [диод SR340]
           │            (катод к +12В)
           │               │
           ├───────► PA0 (ADC1_IN0) — низкая сторона мотора
           │          (делитель 10к/2к на GND)
           │
           ├── сток IRLZ44N
           │     исток → GND
           │     затвор ← PA8 (TIM1_CH1) через 100 Ом
           │
           └───► PA1 (ADC1_IN1) — плюс мотора (питание)
                  (делитель 10к/2к на GND)
```

**Ключевая идея:**
- **PA1** измеряет напряжение питания мотора `V_supply` (номинал 12В через делитель).
- **PA0** измеряет напряжение на низкой стороне мотора `V_low` (там сидит BEMF).
- **BEMF = V_supply − V_low** (в паузе, когда IRLZ44N закрыт).

Это позволяет **не зашивать константу 12В в код** — агент сам вычисляет реальное питание в момент замера, что автоматически компенсирует просадку питания под нагрузкой.

### ⚙️ Изменения в конфигурации CubeMX

1. **ADC1** — теперь **два канала**:
   - IN0 (PA0) — низкая сторона мотора.
   - IN1 (PA1) — питание мотора.
   - Режим: **Scan Conversion Mode = Enable**, **Continuous = Disable**, **Number of Conversions = 2**.
   - **DMA:** добавить DMA1 Channel1 (ADC1), режим Circular, чтобы два канала читались без блокировки.
   - Sampling Time: **71.5 cycles** для обоих каналов.
   - Software trigger (запуск из процедуры BEMF-паузы).

2. **PA1** должен быть в режиме **Analog** (не GPIO).

### 🔬 Обновлённый алгоритм замера BEMF

1. TIM1 останавливается, IRLZ44N закрыт, пауза 1 мс.
2. Запускается ADC1 с DMA, читаются **два значения**: `adc_low` (PA0), `adc_supply` (PA1).
3. Пересчёт:
   ```c
   float v_low    = adc_low    * VREF / 4095.0f * (R1 + R2) / R2;
   float v_supply = adc_supply * VREF / 4095.0f * (R1 + R2) / R2;
   float v_bemf   = v_supply - v_low;   // чистая ЭДС
   ```
4. `RPM = v_bemf × K_motor × sign` (знак учитывает направление вращения).
5. TIM1 возобновляет ШИМ.

### 🛡️ Дополнительные проверки (добавить в fault.c)

1. **Проверка питания:** если `v_supply < 6В` — fault (`SUPPLY_LOW`), ШИМ = 0.
2. **Проверка достоверности:** если `v_bemf < 0` или `v_bemf > v_supply` — замер отбросить, не обновлять RPM.
3. **Защита от обрыва:** если `adc_low == 0` и `adc_supply == 0` три замера подряд — fault (`SENSOR_FAULT`).
